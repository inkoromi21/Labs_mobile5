# Лабораторная работа № 5

## Задание

Создать калькулятор чаевых и приложение для просмотра картин на Kotlin с Jetpack Compose.

## Выполнено

В проекте два приложения:

- `app`: калькулятор чаевых с округлением и тестами.
- `artspace`: просмотр трёх картин с названием, автором, годом и кнопками переключения.
